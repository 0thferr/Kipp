# Kipp — Sistema de câmeras

O projeto acompanha a evolução de um visualizador de transmissões HLS. As duas versões são aplicações Vue 3 com Vite e hls.js.

- [Versão 1.0](projeto-camera1.0/README.md) reúne a implementação inicial.
- [Versão 2.0](projeto-camera2.0/README.md) organiza a grade, a página de cada câmera e os testes automatizados.

Para rodar uma versão, entre na pasta correspondente e execute:

```bash
npm ci
npm run dev
```

Use `npm run build` na mesma pasta para compilar para produção. Consulte a documentação da versão 2.0 para configurar o stream e executar os testes.
